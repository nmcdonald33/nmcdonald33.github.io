Automated Jewelry Sorter

A Raspberry Pi-powered gantry system that uses computer vision to detect and sort jewelry by size — designed to solve the age-old problem of untangling your necklaces at 11pm.

Raspberry Pi Python Computer vision Gantry control Mechanical design

The problem

For ME 3024 (Engineering Design and Economics), our team identified a real pain point: busy college students and working women who love jewelry but hate the nightly ritual of removing, sorting, and storing it. The solution: an automated system that does it for you.

The system uses a Raspberry Pi and a camera to identify each piece of jewelry based on its size using image processing, then commands a gantry to pick it up and move it to an assigned storage compartment. The result is a semi-functional prototype that demonstrates the core detection-and-sort pipeline end to end.

System breakdown

Vision system

A camera feeds live frames to a Python image processing script running on the Raspberry Pi. The script detects the bounding box of each jewelry piece and classifies it by size into one of several categories (ring, bracelet, necklace).

Gantry control

Based on the detected size category, the Raspberry Pi commands stepper motors to move the gantry to the correct X-Y position above the assigned storage compartment, then actuates a drop mechanism.

Mechanical design

The gantry frame was designed for low cost and ease of fabrication. Rails and carriages were specified for smooth motion with minimal backlash, keeping sorting precision within the compartment boundaries.

Software pipeline

The full pipeline — capture → process → classify → command → actuate — runs in a continuous loop. Error handling accounts for misdetections and mechanical overruns.
