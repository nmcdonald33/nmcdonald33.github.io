About Machworks

Machworks is an interdisciplinary undergraduate design team at Virginia Tech working to become the first undergraduate group to design and build an autonomous turbojet capable of reaching supersonic speeds. I was a member of the propulsion sub-team, working on two parallel efforts — engine modeling and afterburner design.

Turbojet engine model

My primary contribution was developing a dynamic model of the jet engine using MATLAB, Simulink, and System Identification. The goal was to characterize the relationship between throttle control position and thrust output, then develop a model that the team could use for control system development.

I used a rotary encoder and Raspberry Pi to record the position of a servo as it moved in response to input commands, logging everything to a CSV file. That data became the basis for the System ID model in Simulink.

Data collection

Python script on Raspberry Pi reads a rotary encoder and logs servo position + timestamp to CSV at high frequency. Designed to capture both step and sweep inputs.

System ID

Used MATLAB's System Identification Toolbox to fit a transfer function model to the collected servo position data. Validated the model against held-out test data.

Simulink model

Built a Simulink block diagram representing the throttle-to-thrust relationship, ready for integration with the team's flight dynamics and control systems work.

Afterburner diffuser design

Over the summer, I also contributed to the design of an afterburner for the current jet platform. My specific task was the diffuser — the component that slows and spreads exhaust gas before it enters the afterburner combustion zone. I researched diffuser geometry theory, ran preliminary analyses, and built a full CAD model in Autodesk Fusion 360.

The work was compiled into a formal report and passed to the next cohort of students on the team in Fall 2024, giving them a starting point for physical fabrication.
